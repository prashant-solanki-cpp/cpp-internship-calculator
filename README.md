# C++ Calculator

A simple console-based calculator developed in C++ as part of my C/C++ Development Internship at Auspify Technologies.

## Features

- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Input validation for menu choices and numeric inputs
- Division-by-zero protection
- Menu-driven interface with an exit option

## Technologies Used

- **Language:** C++
- **Compiler:** GCC (g++)

## How to Run

### 1. Compile the program

Open a terminal in the project folder and run:

```bash
g++ cpp_internship_calculator.cpp -o calculator
```

### 2. Run the program

On Windows PowerShell:

```powershell
.\calculator.exe
```

On Linux:

```bash
./calculator
```
